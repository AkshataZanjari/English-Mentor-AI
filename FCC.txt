1---“Good morning everyone.
Today I am going to present Cloud Computing Services Used by Netflix.

2---Netflix is one of the world’s largest cloud-native streaming platforms, with millions of users watching movies and web series simultaneously. Today, Netflix serves over 300 million paid subscribers across 190-plus countries, generating more than 45 billion dollars a year. To handle this huge amount of traffic smoothly, Netflix relies heavily on Amazon Web Services (AWS) and other cloud technologies. These cloud services can automatically increase resources when demand is high and reduce them when demand is low. This provides Netflix with elastic scalability, high availability, global reach, security, cost optimization, and automation, ultimately helping it deliver better streaming experience.


4---“First, we have Amazon EC2.You can think of EC2 as the computers that run Netflix's application. Whenever we open Netflix, search for a movie, or click Play, EC2 processes those requests.
For example, during peak hours, such as evenings or weekends, a large number of users may access Netflix at the same time. During this period, Netflix needs more computing resources to handle all these requests. EC2 allows Netflix to scale up its resources according to the demand.

Therefore, Amazon EC2 helps Netflix handle a large number of users efficiently and maintain its performance.

Then, AWS Auto Scaling automatically creates more EC2 servers to handle the extra traffic.For example, when traffic suddenly increases because a new episode is released, Auto Scaling launches additional EC2 instances.
When the traffic decreases, unnecessary instances are removed.

5---Moving on to storage service, an important question is — where does Netflix store all its movies, web series, and other data? Well, Netflix uses Amazon S3 to store its movies, shows, and application files. This allows Netflix to safely store and manage a massive amount of content in the cloud.
Netflix can also store different versions of the same content, such as different video qualities like HD or 4K, so that the appropriate version can be provided to the user.

For content that is rarely accessed, Netflix can use Amazon Glacier for lower-cost archival storage.

6---Netflix uses Amazon CloudFront, which is a Content Delivery Network or CDN. Instead of sending videos from one central location, CloudFront delivers the content from the server closest to the user, which helps Netflix provide smoother streaming with less buffering. Netflix also operates its own CDN called Open Connect, which is specifically designed for delivering Netflix video content. where as CloudFront’s role here is accelerating the website, sign-up flow, images, and API traffic.

It also uses Route 53 which is AWS's highly available DNS service  which directs users to the nearest available AWS server.

--------------------------------------------------------------------------
Netflix also needs to remember every user's activity.
For example, it remembers what you've watched, where you stopped watching, and what movies it should recommend next.
This information is stored using Amazon DynamoDB, which is a very fast NoSQL database.

The final technology I am going to explain is Netflix Open Connect.
Open Connect is Netflix's own content delivery network, designed specifically to help deliver Netflix videos efficiently.
for example.
Suppose a Netflix video is stored far away from you.
If every time you press Play, the video has to travel from a distant location to your device, it can increase delay and may cause buffering.
Netflix solves this problem by placing Open Connect servers closer to users.
Before a show becomes extremely popular, Netflix can predict what content is likely to be watched frequently in a particular area.
Popular content can then be placed on nearby Open Connect servers.
So when you press Play, the video can be delivered from a server that is geographically and network-wise closer to you instead of always coming from a distant location.
