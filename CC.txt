🎤 Slide 3 – AWS Compute Services

“First, we have AWS Compute Services.

In that, Netflix uses Amazon EC2 to run its applications and backend systems.You can think of EC2 as the computers that run Netflix's application. Whenever we open Netflix, search for a movie, or click Play, EC2 processes those requests.

Then, AWS Auto Scaling automatically creates more EC2 servers to handle the extra traffic.

Elastic Load Balancer Instead of sending all users to one server, it distributes the traffic across multiple servers. This keeps any single server from getting overloaded or crashing.

Netflix uses these services to avoid server overload and maintain high availability.”

🎤 Slide 4 – AWS Storage Services

Moving on to storage services, an important question is — where does Netflix store all its movies, web series, and other data? Well, Netflix uses Amazon S3 to store its movies, shows, and application files. This allows Netflix to safely store and manage a massive amount of content in the cloud

Next, Amazon EBS provides storage that is connected to the EC2 servers. It is useful for storing data that the applications running on those servers need.

For older or rarely accessed content, Netflix use Amazon Glacier for low-cost long-term storage.

These services provide secure, durable, and cost-effective storage.”

🎤 Slide 5 – Networking and Content Delivery

Even if Netflix stores videos in the cloud, users expect them to start playing almost instantly.

This is where networking services become important.

Netflix uses Amazon CloudFront, which is a Content Delivery Network or CDN. Instead of sending videos from one central location, CloudFront delivers the content from the server closest to the user, which helps Netflix provide smoother streaming with less buffering.

It also uses Route 53, which directs users to the nearest available server.

Finally, we have Amazon VPC, which focuses on security. It creates secure network for Netflix's cloud resources. This helps Netflix's servers and other cloud services communicate within a controlled environment.

These services reduce buffering, improve streaming speed, and provide better security

🎤 Slide 6 – Database and Monitoring

Netflix also needs to remember every user's activity.

For example, it remembers what you've watched, where you stopped watching, and what movies it should recommend next.

This information is stored using Amazon DynamoDB, which is a very fast NoSQL database.

Apart from DynamoDB, Netflix also uses Amazon RDS. which is useful when information needs to be stored in an organized structure, usually in tables. For example, data such as user or account-related information can be managed in a structured way using a relational database.

To make sure everything is working properly, Netflix uses CloudWatch, which continuously monitors system performance.

For security and auditing, it uses CloudTrail, which records every important activity happening in the cloud.

These services help Netflix provide personalized recommendations while keeping the platform secure and reliable.
